## 带宽要选哪一档，这一步比选套餐更影响体验

两台独服的带宽都是下单时三选一，官方给的选项差异很大：

香港独服可以选 10Mbps 优化、15Mbps 普通回国、20Mbps 国际。洛杉矶独服可以选 50Mbps 优化、200Mbps 普通回国、300Mbps 国际。

选“优化”拿到的是质量最高的回国线路，代价是带宽数字小。选“国际”带宽翻几倍，但国内访问走的是普通出口。这个取舍没有标准答案：面向国内用户的后台、企业站、需要频繁上传下载的，10M 或 50M 优化比 300M 国际实用；做海外访客为主的站点、跑下载或视频中转，带宽数字才是瓶颈。

洛杉矶独服那台尤其值得算一下。$40/月拿到 200Mbps 普通回国或 300Mbps 国际，配 8 核 8G 和 1T 硬盘，这个组合在同价位里属于配置给得多的类型；但如果你的用户主要在国内，50M 优化档的实际体验会比 300M 国际档更稳。

## 常见问题

**续费真的不涨吗？**
活动条款第一条写的是“续费同价”，促销价同样适用于续费。这是官方条款原文，不是推测。

**优惠码和长周期折扣能一起用吗？**
可以。条款第二条写明季付、半年付、年付都适用本次促销，并且可以和额外折扣叠加。

**优惠码在哪里填？**
结账页面有独立的优惠码输入框，四款分别对应 `SGCLOUD50`、`SJCLOUD50`、`LAE52660`、`HKGOLD30`。填完确认价格变成表里的特价再付款。

**新加坡那台 10Mbps 是不是太小？**
看用途。跑静态站、做跳板、当测试环境够用；跑有图片和视频的站点、或者有并发下载，10Mbps 会顶到天花板。这种需求直接上圣何塞那台 1Gbps。

**香港和洛杉矶的独服，哪个更适合国内用户？**
香港机房物理距离近，10Mbps 优化档的往返延迟通常更低；洛杉矶那台 50Mbps 优化档带宽大五倍，适合流量更大的场景。两边都是优化线路，取舍在延迟和带宽之间。

**什么时候结束？**
官方没有公布截止日期，写的是限量供应、售完即止。四款各自的库存上限是 20、30、50、50 台。
